# Demo direction

Quiet, technical, legible. System sans for controls and Georgia for the heading; muted green and warm white tie the simulator to the existing console without implying a physical bench is online. A two-column campaign control and evidence layout collapses to one column on mobile. Spacing uses 8px increments. Controls use explicit labels and clear focus; state changes update the history. The signature element is the prominent simulation notice, which anchors every result in its actual source.
