# ChipCheck Console

The console collects a test setup in five steps: setup identity, controllable inputs, required evidence, reviewed limits and budget, then review. The proposed tests view is a labeled mock preview until the BFF is connected. It does not select candidates, check bench safety, or execute hardware.

Run with Node.js 20 or newer:

```bash
npm ci
npm run dev
```

Open http://localhost:3000. Use `npm run build` to verify a production build.
